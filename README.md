# Визуальные тесты карточки кофемолки

Учебный React-компонент для статьи о Storybook и Playwright. Сценарий воспроизводит правку отступов кнопки на двух ширинах и показывает, как принять новый эталон после исправления CSS.

## Запуск

Эталоны записаны на Debian 13 x86-64, Node 24, Chromium 147 из `@sparticuz/chromium` и системном Liberation Sans. Используйте Linux x86-64 с этим шрифтом для сравнения с готовыми эталонами. Для Docker предусмотрен Dockerfile. В нативном macOS или Windows требуется `npx playwright install chromium` и отдельные эталоны для своей платформы.

```bash
npm ci
npm run storybook
```

Storybook открывается на http://127.0.0.1:6006. В дереве выберите Components → ProductCard → Narrow или Wide. Остановите сервер разработки перед запуском тестов. Playwright запускает собственный сервер на том же порту и раздает статическую сборку.

```bash
npm run build
npm test
```

Для ручной проверки статики есть `npm run serve`. HTML-отчет после прогона открывается через `npx playwright show-report`. Снимки упавших проверок появятся в `test-results/`.

## Повторить весь цикл

Если вы скачали ZIP, внутри также есть `coffee-visual-demo.bundle`. Из папки с распакованными файлами выполните `git clone -b main coffee-visual-demo.bundle coffee-visual-demo-history` и перейдите в полученный репозиторий. В архиве доступны теги. В публичном репозитории те же версии доступны в ветках с такими же именами.

| Версия | Что в коде | Что покажет `npm test` |
| --- | --- | --- |
| `baseline` | Отступы `8px 12px`, высота 320 px | Три проверки проходят. |
| `broken` | Отступы `8px 40px`, высота 320 px | Две визуальные проверки падают. Корзина проходит. |
| `fixed` | Отступы прежние, высота растет, цена видна | Новый вид расходится со старыми эталонами. Корзина проходит. |
| `approved` | Снимки исправленной карточки приняты | Три проверки проходят. |

Для GitHub переключайтесь командой `git switch --detach origin/<ветка>`. Для архива используйте `git switch --detach <тег>`. После переключения каждый раз запускайте `npm run build` и `npm test`. На `broken` изучите expected, actual и diff. При 220 px пропадает цена. При 320 px меняется ширина кнопки, цена видна. На `fixed` сверьте оба новых кадра с задачей, затем обновите эталоны и повторите прогон.

```bash
npm test -- --update-snapshots=changed
npm test
```

Обновление записывает файлы снимков в рабочую копию. В версии `approved` оба снимка уже включены в коммит. Для первого сохранения отсутствующих эталонов можно использовать `npm test -- --update-snapshots=all`, затем проверить кадры и запустить `npm test`.

## Результаты прогона из статьи

- `evidence/broken/` содержит оригинальные PNG двух падений, включая expected, actual и diff.
- `evidence/fixed/` содержит результаты сравнения исправленной карточки со старым эталоном.
- `evidence/*-results.txt` содержит вывод Playwright до исправления, после исправления и после принятия эталонов.
- Изображения `*-comparison.png` собраны из этих снимков. Подписи добавлены отдельно.
- Фото кофемолки в `public/fixtures/grinder.jpg` сгенерировано для учебного примера.
